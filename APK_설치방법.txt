================================================================
  Chronicles of Aetheria - APK 다운로드 & 설치 방법
================================================================

[ 1단계 - GitHub Actions에서 APK 다운로드 ]

1. 아래 주소로 이동
   https://github.com/galmegi1234/Rpg/actions

2. 목록에서 가장 최근 "Build Android APK" 클릭

3. 페이지 맨 아래 "Artifacts" 섹션에서
   "Chronicles_of_Aetheria-Android-APK" 클릭 → ZIP 다운로드

4. ZIP 압축 해제 → Chronicles_of_Aetheria.apk 파일 나옴


[ 2단계 - 안드로이드 설치 ]

1. 설정 → 보안 (또는 애플리케이션)
   → "알 수 없는 출처 허용" 켜기
   (기기마다 위치 다를 수 있음)

2. APK 파일 탭 → 설치


[ 조작법 ]

이동      : 왼쪽 가상 조이스틱
공격      : 오른쪽 ⚔ 버튼
포션 사용 : 🧪 버튼 (HP 자동 회복)
회피      : 💨 버튼 (무적 프레임)
인벤토리  : 🎒 버튼
상점      : 🛒 버튼
일시정지  : ⏸ 버튼


[ 게임 흐름 ]

마을 스폰 → 평원(Lv1) → 숲(Lv5) → 던전(Lv10)
각 지역 끝 포털로 이동 / 마을 상점에서 아이템 구매·강화·소환
